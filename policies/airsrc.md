# AirSRC 规则摘录（基于 2026-10-27 用户提供的页面截图）

> 本文件用于提交前人工核对，不替代 AirSRC 的实时公告、完整接收规则或等级标准。截图可能被裁切，规则也可能变更。

## 报告与隐私要求

- 报告应包括网站 URL、功能模块、前置条件、操作步骤、请求数据包及所用工具名称。
- 测试中应保护用户隐私、数据机密性与完整性。
- 不得访问其他用户数据；涉及其他用户时，只能使用本人账号或已获账号持有人明确许可的账号。
- 漏洞修复前不得公开已经提交给 AirSRC 的漏洞。
- 不得从事违法行为或利用安全问题损害用户。

## 测试限制

- 不得大量创建账号。
- 不得以暴力枚举方式测试 API 或功能的速率限制。
- 不得进行钓鱼、电话社会工程、电信诈骗等社会工程攻击。
- 不得侵犯隐私、破坏数据完整性、中断或影响服务。
- Log4j 导致的 RCE 在接收范围内，但 Log4j 导致的 DoS 不在接收范围内；实际测试仍须采用无破坏验证。

## 截图列出的不接收项

1. 内部已知且正在整改的漏洞
2. 短信或邮件轰炸等速率限制问题
3. 拒绝服务攻击
4. 钓鱼攻击
5. 社会工程攻击
6. 反射型文件下载
7. 软件版本泄露
8. 需要直接物理访问的漏洞
9. 需要用户交互但无法产生用户交互的漏洞
10. 只影响旧版浏览器或插件的缺陷
11. 登录界面可从公网访问
12. CSV 注入
13. 电子邮件枚举或账号猜测
14. CSP 配置缺陷
15. 电子邮件欺骗
16. 内容过滤绕过，包括被替换为 `Hidden by Airbnb` 的敏感信息
17. 能查看其他用户已公开的个人资料或照片
18. 无效链接或冒充社交媒体账号（恶意利用除外）
19. DNS Log、Burp Collaborator 等仅记录到 DNS 请求但没有敏感信息的发现
20. 无法造成严重危害的前端 API Key 泄露

## 截图中可见的资产范围

- 爱彼迎移动版 iOS、Android、鸿蒙应用
- 微信小程序“Airbnb爱彼迎民宿预订”
- `*.airbnb.cn`
- `zh.airbnb.com`

移动应用与小程序不能由当前 Web 扫描器覆盖；需在专门测试环境中按照平台规则人工测试。域名列表来自截图，使用前应在官方页面重新确认。
